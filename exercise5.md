# Easy Exercise 5: Greet User

**Goal**: Write a JavaScript function that takes a `name` as an argument and returns a greeting string like "Hello, [name]!".

```js
function greetUser(name) {
  return `Hello, ${name}!`;
}

console.log(greetUser("Alice")); // Expected: "Hello, Alice!"
console.log(greetUser("Bob")); // Expected: "Hello, Bob!"
```

**What to learn**: Function definition, parameters, string concatenation/template literals.
