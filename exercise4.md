# Easy Exercise 4: Calculate Area of a Rectangle

**Goal**: Write a JavaScript function that takes `length` and `width` as arguments and returns the area of a rectangle.

```js
function calculateRectangleArea(length, width) {
  return length * width;
}

console.log("Area of 10x5 rectangle:", calculateRectangleArea(10, 5)); // Expected: 50
console.log("Area of 7x3 rectangle:", calculateRectangleArea(7, 3)); // Expected: 21
```

**What to learn**: Function definition, parameters, return statement, basic multiplication.
