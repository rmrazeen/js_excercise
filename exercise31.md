# Exercise 2: Variables and Data Types

**Goal**: Declare variables of different data types (string, number, boolean, array, object) and print their values and types to the console.

```js
let name = "Alice";
let age = 30;
let isStudent = false;
let hobbies = ["reading", "hiking", "coding"];
let person = {
  firstName: "John",
  lastName: "Doe",
  age: 25
};

console.log("Name:", name, "Type:", typeof name);
console.log("Age:", age, "Type:", typeof age);
console.log("Is Student:", isStudent, "Type:", typeof isStudent);
console.log("Hobbies:", hobbies, "Type:", typeof hobbies);
console.log("Person:", person, "Type:", typeof person);
```

**What to learn**: Variable declaration (`let`, `const`), basic data types (string, number, boolean), complex data types (array, object), `typeof` operator.
